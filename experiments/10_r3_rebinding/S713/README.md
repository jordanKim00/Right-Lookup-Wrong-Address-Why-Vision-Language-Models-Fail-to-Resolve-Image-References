# S713

Category: `10_r3_rebinding`. R3 (Read, Resolve, Rebind): calibration, Read selection, the two writes, their mechanism tests and other families.

From the main script's docstring:

> S713: R³-v2 with the 27B model-internal readers on natural benchmarks, through the unchanged S582 harness (exp/s582_evalrepair.run: same items, prompts, splits, restricted option-letter argmax and paired base/repair readout as the saved small-model rows). The repair is exp/r3_min_md.R3MinMD (R³-min plan + the S711 frame-only rule; readers / calibration exp/s709_cal.py, base r327b) -- nothing is fitted or tuned on benchmark items. Pre-registration in knowledge/DECISIONS.md before any S713 data. Usage: python s713_mmiu.py MODEL TAG --base B --suites S [--sealed | --fresh] [--rev_style end] [--ca
