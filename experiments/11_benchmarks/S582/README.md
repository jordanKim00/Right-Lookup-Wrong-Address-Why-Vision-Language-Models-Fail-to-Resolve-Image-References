# S582

Category: `11_benchmarks`. MMIU and MuirBench evaluation harness and the per-item benchmark results.

From the main script's docstring:

> S582: one evaluation for every repair -- the base model and the repaired model on the SAME items, paired. Repairs: lora (S579 circuit-band adapters), lrt0 (S580), lrt1 (S581). Suites: efficacy mmiu_pos -- MMIU's 11 option-list position tasks, forward form and reverse form ("... from the end") cloze -- MMIU visual_cloze, NATURALLY reverse options ("The k-th image from the end"), and its forward rewrite muir -- MUIRBench position items (S491 selection), forward and reverse forms locality mmiu_other-- MMIU tasks whose options are not image references (correspondence, NLVR2, MaRVL, quality, ...) i
